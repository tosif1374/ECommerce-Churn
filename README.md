E-Commerce Customer Churn Prediction is a Machine Learning project that predicts whether a customer is likely to leave (churn) or continue using the platform.

Customer churn is a critical business problem because acquiring new customers costs significantly more than retaining existing ones. This model helps businesses identify at-risk customers early and take preventive actions.

🎯 Problem Statement

The objective of this project is to build a classification model that predicts:

1 → Customer Will Churn

0 → Customer Will Stay

Using customer behavioral and transactional data.

🧠 Machine Learning Approach

The project follows a complete ML pipeline:

Data Collection

Data Cleaning & Preprocessing

Exploratory Data Analysis (EDA)

Feature Engineering

Model Training

Model Evaluation

Model Deployment
